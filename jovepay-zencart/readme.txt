1. Upload all of the included folders and files to your Zen Cart directory
2. Log in to your Zen Cart admin and navigate to Modules > Payment
3. Locate and click on the JOVEpay module, then click on the Install button
4. On the resulting page, enter your JOVEpay API Key and JOVEpay IPN Secret.
5. Optionally, you can also set the Sort Order of the JOVEpay module, the Default Order Status for orders placed using the JOVEpay module and specify a Payment Zone in order to restrict the availability of the JOVEpay module to certain geographic locations.
6. Click on the Update button.
7. The JOVEpay module is now installed, configured and ready for use.
